# Security

On Page Media Downloader stores On Page API tokens (encrypted with the operating system's credential store) and writes files in folders the user chooses. Please report vulnerabilities privately, not in public issues: use GitHub's "Report a vulnerability" (Security › Advisories) on this repository.

Include the version, the operating system, what an attacker can do and the steps to reproduce. You will get an answer within a few working days; fixes are released as a new version and noted in the CHANGELOG.

Supported versions: the latest 2.x release.
