# Contributing

1. Fork, create a branch, keep commits small and focused.
2. Install Node.js 24 with Yarn 1, and Rust (stable, through rustup) with what [Tauri needs on your system](https://v2.tauri.app/start/prerequisites/) (the MSVC build tools on Windows, Xcode's command line tools on macOS, the WebKitGTK development packages on Linux). Then `yarn` (no token needed) and `yarn dev`: the app starts with its own data folder (`op-media-downloader-dev`, or the one in `OPMD_USER_DATA`), never the installed app's.
3. Before a pull request: `yarn typecheck`, `yarn lint`, `yarn format:check`, `yarn test`, `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`. CI runs the same checks on Windows, macOS and Linux and packages the app.
4. Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) first: the safety rules (the app only removes what it created, never overwrites files it does not know) are not negotiable, and changes to the sync service (`crates/op-media-service`) need tests, including the fault-injection ones.
5. User-visible texts go through vue-i18n (the page) or `src-tauri/src/i18n.rs` (the app: notifications, tray, dialogs, menu) in all eight languages: Italian, English, German, Spanish, French, Russian, Swedish, Chinese. `src/renderer/src/i18n/messages.test.ts` checks the keys, the placeholders and the plural forms of the page.
6. Never commit Font Awesome Pro material (`src/renderer/src/lib/icons/pro.generated.ts` is ignored on purpose) or other proprietary assets.
7. Formatting-only commits are listed in `.git-blame-ignore-revs`: run `git config blame.ignoreRevsFile .git-blame-ignore-revs` once and `git blame` skips them, as GitHub does. Add the commit of any new repository-wide formatting there.
8. The app icons (`build/icon.icon`, `build/icon.icns`, `build/icon.ico`, `build/icons/`, the tray and the title bar) are drawn by `scripts/app-icons.mjs`: change the drawing there and run `yarn app-icons`, which needs `vectorcraft-cli` from [VectorCraft](https://getartcraft.com/apps/vectorcraft). The bundle takes its icons and the tray pictures from `src-tauri/icons`: copy them there after a new drawing.
